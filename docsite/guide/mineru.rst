MinerU 转换
===========

所有已入库 PDF 由 MinerU **VLM 模型** 转换为带图片的 Markdown
（正文 ``.md`` + 图片 zip）。

调度规则
--------

- 每天 0 点自动启动一轮批量转换，**每日上限 4000 篇**\（保留约 1000 篇的
  灵活余量）；
- 待转换队列清空、无可用 API token、或 API 额度耗尽时报错即停，次日 0 点再续；
- 同一时刻只有一个转换进程：定时任务触发时若上一轮仍在运行，不会重复启动；
- 服务重启后会自动续跑当日的转换队列；
- 单篇转换失败（如 MinerU 偶发解析错误）会跳过并继续，不会中断整轮。

查看进度
--------

- 管理后台（``/zh/admin``）可查看调度器状态：是否在运行、今日已转换数、
  下次运行时间，并可手动触发一轮（见 :doc:`admin`）；
- 已转换论文在首页「已转换论文」区块与论文列表（``has_md`` 过滤）中展示；
- 论文详情的 ``/api/papers/{id}/markdown`` 与 ``/api/papers/{id}/images``
  在转换完成后即可访问。
